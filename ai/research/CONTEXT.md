# Targeted research and narrative design

Research techniques, comparable cases and compatibility under
[RULES.md](../RULES.md). The four-table methodology is already selected.

## Inputs

| Input | Read scope |
|---|---|
| Selected task card | Scenario, question, current stage and endpoint |
| Selected runner/README and existing workflow | Behavior and assumptions; disclosed design knowledge |
| Primary sources | Material relevant to the specific research question |
| [Toolbox](../../docs/linux-dfir-toolbox.md) | Only the needed technique section and citations |
| Approved preview linked from RULES | Table layout only when planning results |

## Process

1. For comparable-case research, read 2–3 close practitioner investigations or
   original studies. A tool manual verifies syntax but is not a comparable
   incident. For a narrower question, use only the sources it needs.
2. Record source/date, mechanism, examination order, evidence, useful pivots,
   post-mortem applicability and material differences. Report source shortfalls.
3. Adapt a question-led narrative. Separate sourced facts, design inference,
   expected scenario effects and unanswered evidence questions. Do not prescribe
   source eligibility in claims or treat design knowledge as a discovery.
4. Propose only a justified minimal scenario change. Missing independent
   validation remains a limitation; do not propose extra guest readbacks merely
   to strengthen the reference or force a positive result.
5. Propose commands and bounded feasibility checks without predicting verdicts.
   Evidence execution belongs to a selected forensic section; acquisition belongs
   to experiments. Do not perform those stages under a research-only brief.

## Outputs and endpoint

Update existing case research/workflow material with citations, adaptations and
limits; create a small case note only when necessary. Hand off the next bounded
step. Continue into code/experiments only when already authorized and the design
is unchanged; otherwise present the proposal for human review. No notebook
advancement, forensic support verdict or metric-selection research occurs here.
